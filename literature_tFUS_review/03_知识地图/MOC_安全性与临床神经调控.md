# MOC：安全性与临床神经调控

## 核心问题

低强度经颅聚焦超声（tFUS）在神经调控中的安全性是临床转化的前提。核心挑战包括：剂量报告标准化、温升与机械效应的分离、不同靶区和受试人群的安全阈值差异，以及动物实验向人体证据的可迁移性。

## 关键参数与安全阈值

- [[05_论文与概念/concepts/MI|MI]] ≤ 1.9（ITRUSST 推荐 NSR）
- 脑内温升 ≤ 2°C 或 ≤ 39°C
- CEM43 热剂量阈值
- ISPTA、ISPPA 报告标准
- 频率范围：0.2-0.7 MHz（低频有利穿透但需更严格安全评估）
