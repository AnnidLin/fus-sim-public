# 实验指导型文献清单

这份清单回答一个更实际的问题：

> 哪些论文/工具真的能指导我们的实验和平台下一步，而不只是“相关”？

结论先说：  
你现在最需要看的不是更多散文综述，而是下面 5 类“能转成实验动作”的资料。

## 1. 直接指导当前实验 baseline

### G01：高鹏皓 2022 本地论文

用途：作为第一个可复现 baseline。

它能指导：

- 单阵元换能器几何。
- CT 颅骨建模。
- k-Wave 声场仿真。
- 换能器定位。
- Pennes 热效应。
- 42°C 粗安全阈值。

可以用的参数：

- `500 kHz`
- `1 MPa source pressure`
- `6% duty`
- `PRF = 300 Hz`
- `67 ms train`
- `2.5 s interval`
- `aperture = 25 mm`
- `radius = 30 mm`

注意：

- 这些是高鹏皓论文的 seed protocol，不是整个领域共识。
- `1 MPa` 要写成 source/excitation pressure，不能直接写成颅内焦点声压。

下一步动作：

- 生成 `gao2022_baseline` 参数 profile。
- 先做自由场校准，再做 CT 颅骨声场。

## 2. 指导仿真平台怎么搭

### G02：Treeby & Cox 2010 k-Wave

用途：解释 k-Wave 是什么、PML/网格/时间步长为什么重要。

它能指导：

- 声场仿真基础。
- PML 边界设置。
- source/sensor 输出。
- time reversal 概念。

下一步动作：

- 在 `fus-sim` 报告里加入 `dx / PPW / PML / CFL / simulation time`。

### G03：TUSX / PRESTUS

用途：学习公开工具如何组织一个完整仿真 pipeline。

它能指导：

- 输入影像怎么组织。
- target/entry 怎么记录。
- 声场和热场输出如何报告。
- case report 应该有哪些字段。

下一步动作：

- 把 `fus-sim` 的报告格式向 PRESTUS/TUSX 靠拢。
- 输出标准 `case_report` 模板。

### G15：BabelBrain

用途：学习成熟工具如何组织 transducer profile、声场输出和热模型。

它能指导：

- 换能器 profile 化。
- CT/MRI/ZTE/PETRA 输入组织。
- 声场和热场联动报告。

下一步动作：

- 为 `fus-sim` 建立 `transducer_profile.json`。
- 把 current tuned 参数和 Gao baseline 参数分开。

## 3. 指导 entry/target 规划

### G04：PlanTUS

用途：把我们当前的 entry/target 候选从“盲扫”变成“有解释的规划”。

它能指导：

- target-to-skin distance。
- transducer tilt。
- skull/skin normal angle。
- avoidance region。
- 候选排序指标。

下一步动作：

- 给 `scan_ct_entry_positions.py` 增加几何解释指标。
- 输出 ranked candidate 时，不只给声压，还给几何原因。

## 4. 指导安全和汇报规范

### G06/G07/G08：ITRUSST 指南系列

用途：告诉你实验参数怎么报告、哪些安全信息必须写清楚。

它能指导：

- 参数定义统一。
- 声压/声强/MI/占空比的报告。
- 安全性说明。
- 生物物理风险边界。

下一步动作：

- 汇报里明确区分：
  - `source pressure`
  - `free-field pressure`
  - `in situ pressure`
  - `PNP`
  - `pulse duty`
  - `protocol-average duty`

### G09：Mueller 2016 温升仿真

用途：补充为什么神经调控参数下也要做热安全评估。

它能指导：

- 颅骨和脑组织温升量级。
- 低强度 tFUS 的热安全解释。
- 材料参数敏感性意识。

下一步动作：

- 在 Pennes 报告里说明目标点温升、全局最高温、颅骨最高温。

## 5. 指导后续相位校正和高阶复现

### G05：Kranion / Jin 2020

用途：学习颅骨相位校正和水槽验证。

它能指导：

- ray-based phase correction。
- hydrophone scan 验证。
- 颅骨导致焦点偏移怎么补偿。

下一步动作：

- 先做自由场校准。
- 再考虑相位校正。
- 不要跳过单阵元 baseline 直接上复杂相控阵。

### G16：Leung 2019 rapid beam simulation

用途：学习快速预筛和更高可信验证之间的关系。

它能指导：

- 为什么 quick run 只能叫筛选。
- 如何用更可靠实验或 MR thermometry 对齐。

下一步动作：

- 把当前 quick k-Wave 结果标记为 screening。
- 单独设计论文级大网格复核。

## 6. 只作为相关内容补充，不进入当前实验参数

### G17：潘婷 BBB + 微泡

用途：补充 BBB、微泡、MI、PCD、空化监测知识。

不能做的事：

- 不能把 `MI 0.3-0.7` 当作神经调控默认参数。
- 不能把微泡密度用于当前无微泡仿真。

### G18：孙天宇溶栓

用途：补充高强度空化/溶栓方向。

不能做的事：

- 不能把 `-6/-8 MPa` 当作低强度 tFUS 神经调控目标。
- 不能把溶栓最优频率直接写成神经调控最优频率。

## 8. 建议你向师姐汇报时这样说

目前文献整理已经从“找相关论文”升级为“按实验用途分层”：

- 第一层是直接复现 baseline：高鹏皓论文。
- 第二层是仿真平台方法依据：k-Wave、TUSX/PRESTUS、BabelBrain。
- 第三层是实验规划依据：PlanTUS、Kranion、Leung rapid beam。
- 第四层是安全和报告规范：ITRUSST、Mueller 2016。
- 第五层是相关方向补充：BBB、微泡、溶栓、热消融，只用于综述和边界说明，不混入当前神经调控参数。

下一步不是继续堆论文，而是把这些文献转成平台动作：

1. 建立 Gao2022 baseline 参数 profile。
2. 做自由场/水槽式校准。
3. 标准化报告 pressure、duty、PPW、PML、CFL。
4. 参数化 CT-HU 声学映射。
5. 再做论文级大网格复核。
