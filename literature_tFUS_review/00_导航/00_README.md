## 本地种子论文

1. `经颅聚焦超声调控系统的参数仿真研究_高鹏皓.pdf`
   - 主线：tFUS 神经调控、CT 颅骨建模、[[05_论文与概念/concepts/k-Wave|k-Wave]] 声压仿真、换能器定位、热效应安全性。
2. `经颅聚焦超声联合微泡开放血脑屏障的数值仿真研究_潘婷.pdf`
   - 主线：FUS + 微泡开放 BBB、Keller-Miksis 微泡动力学、Westervelt/[[05_论文与概念/concepts/Pennes热传导|Pennes]] 数值仿真、[[05_论文与概念/concepts/PCD|被动空化检测]]。
3. `经颅聚焦超声治疗脑血栓的数值仿真研究_孙天宇.pdf`
   - 主线：经颅/开颅聚焦超声溶栓、82 阵元相控换能器、[[05_论文与概念/concepts/时间反转|时间反转]]相位校正、声压阈值与温升。

4. `经颅脑肿瘤HIFU治疗技术的研究现状_韩珍珍.pdf`
   - 主线：脑肿瘤 HIFU 热消融、半球相控阵、CT 个体建模、时间反转、热点消除、Pennes 温度场与 MRI 温控。
   - 来源：参考的本地 PDF；原文件保留在 `<LOCAL_REFERENCE_DATA>\科研项目\`，知识库记录 SHA256，不复制或改写原文。

## 筛选标准

- 必须能通过 DOI、PMID、PMCID、出版社页面或期刊页面核验。
- 优先选择实验步骤、模型参数或复现价值明确的研究论文。
- 三条主题线都覆盖：声场仿真/相位校正、BBB + 微泡、超声溶栓。
- 对无法访问全文的论文，只记录可核验元数据、摘要级信息和可确认方法，不补写无法确认的实验细节。
- 不下载版权不明确的 PDF；`02_大鼠BBB实验/03_原文PDF/` 仅用于保存开放获取且许可允许下载的原文。
- **新增验证导向论文**：优先选择提供可量化验证基准、参数敏感性分析或交叉验证框架的研究，即使不直接涉及 tFUS 应用。

## 建议阅读顺序

### 初次接触（建立全局地图）

1. 先读 `01_seed_papers_summary.md`，明确四篇中文论文分别提供的技术证据。
2. 再读 `03_experimental_steps.md`，把声场仿真、BBB、溶栓三条流程分清。
3. 用 `02_selected_papers_matrix.csv` 和 `05_论文与概念/notes/` 查具体论文。
4. 最后读 `04_theme_synthesis.md`，把这些文献转化为 `fus-sim` 的下一步实现路线。

### 深入某个主题（按 MOC 导航）

- 想学声场仿真 → `MOC_声场仿真与相位校正` → 读取关联的 05_论文与概念/notes/01-04, 14, 21-23, 25-27。
- 想设参数 → `MOC_参数与指标` → 读取 `07_tFUS文献与公开代码参数对照` + `08_参数对齐报告`。
- 想推进虚拟仿真平台 → [[01_虚拟仿真平台/实验平台阶段看板]] → [[03_知识地图/MOC_虚拟仿真平台证据与复现路线]]。
- 想推进大鼠 BBB 实验 → [[02_大鼠BBB实验/00_大鼠BBB实验入口]] → [[02_大鼠BBB实验/01_本地实验/01_本地BBB实验参数对照与参考]]。
- 想验证结果 → `08_参数对齐报告`（第 3 节）→ `05_论文与概念/notes/16_Chen2023`（人体基准）→ `05_论文与概念/notes/14_Montanaro2021`（CT 敏感性）→ `05_论文与概念/notes/25_Pasquinelli2020`（换能器校准）。

### 验证导向（新论文核心价值）

第二批新增论文的核心价值不是"新知识点"，而是"验证方法论"。建议按以下顺序：

1. **Montanaro 2021**（CT 参数敏感性）→ 理解 CT 重建参数如何影响仿真精度。
2. **Chen 2023**（人体基准）→ 建立真实人体颅骨声场的可量化验证基准。
3. **Pasquinelli 2020**（换能器校准）→ 理解为什么自由场验证必须先做。
4. **Li 2026**（交叉验证框架）→ 学习如何设计多种建模策略的对比验证。
5. **Kong 2025**（孔隙率映射）→ 作为未来 mapping profile 的候选方向，但需验证。

## 使用建议

- 在 Obsidian 中打开本文件夹作为 Vault，利用双向链接和图谱视图导航。
- 新增论文时，复制模板到 `05_论文与概念/notes/`，填写结构化字段，然后链接到对应 MOC。
- 修改参数或实验设计时，同步更新 `07_tFUS文献与公开代码参数对照` 和 `08_参数对齐报告`。
- 发现论文之间不一致时，记录到 `MOC_研究问题与争议`。
- 每次搜索补充后，更新 `16_YYYYMMDD_学术搜索补充批次` 格式的新文件，并链接到 `Home` 和 `00_README`。
