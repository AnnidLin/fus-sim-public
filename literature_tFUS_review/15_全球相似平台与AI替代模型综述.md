# 全球相似 tFUS 平台与 AI 替代模型综述

> 用途：补充 `fus-sim` 的平台视野。本文不直接作为代码实现依据，而是作为后续 evidence brief 的来源池，用来判断哪些公开平台值得借鉴、哪些属于中远期方向、哪些说法仍需原文核实。

## 0. 核心结论

- `fus-sim` 当前路线与 **PRESTUS / TUSX** 最接近：都是影像预处理、声学介质、k-Wave 声场、热学和报告的组合式 pipeline。
- **BabelBrain** 对我们最有价值的是 GUI 级输入输出、换能器 profile、热协议组织和报告方式；但其声场后端是 BabelViscoFDTD，不是 k-Wave。
- **PlanTUS** 和 **CoperniFUS** 都提醒我们：真正可用的平台不只需要声场求解，还需要 target/entry/坐标系/定位规划。
- **Kranion / HAS / RapidBeam** 更偏相位校正、快速预估和治疗阵列路线，是中期参考。
- **TFUScapes / DeepTFUS / tFUSFormer** 代表 AI surrogate 方向，短期不应替代物理求解，但适合作为远期加速和数据集组织参考。
- 这些平台和模型应进入 `tool_code_matrix` / `platform_landscape_matrix`，但不能未经核实就变成默认参数。

## 1. 平台对照

| 平台 | 技术路线 | 主要用途 | 对 fus-sim 的借鉴价值 | 当前使用优先级 |
|---|---|---|---|---|
| PRESTUS | MATLAB + k-Wave | MRI/CT 预处理、声场、热学、报告 | pipeline 组织、报告字段、分割到仿真的流程 | 高 |
| TUSX | MATLAB + k-Wave | tFUS 声场仿真、水槽/单阵元验证 | 单阵元、NIfTI 坐标、水槽验证 | 高 |
| BabelBrain | Python GUI + BabelViscoFDTD | 神经调控建模、声场、热效应 | GUI、换能器 profile、热协议和报告 | 中高 |
| PlanTUS | Python 几何规划 | target/entry 候选规划 | 入射角、颅骨厚度、avoidance proxy | 中 |
| Kranion | Java/GPU shader + ray tracing | 相位校正、治疗规划可视化 | hydrophone validation、phase correction | 中 |
| HAS / RapidBeam | 快速角谱/快速声束 | tcMRgFUS 快速预测 | k-Wave 前快速筛选、相位校正参考 | 中 |
| CoperniFUS | Python GUI + stereotaxic planning | 小动物 FUS 实验规划 | 坐标系、脑图谱、实验规划界面 | 中低 |
| TFUScapes / DeepTFUS | dataset + AI surrogate | AI 预测 3D tFUS 声场 | 数据集组织、surrogate 远期加速 | 远期 |
| tFUSFormer | Physics-guided Transformer | 超分辨率/快速预测声场 | AI surrogate 远期参考 | 远期 |

## 2. 对当前平台的启发

### 2.1 近期可直接吸收

1. **PRESTUS / TUSX 式 pipeline**
   - 保持 `CT/NIfTI/DICOM -> acoustic model -> k-Wave -> thermal -> report` 的分层。
   - 每个阶段输出 summary 和可追溯 profile。
   - 自由场/水槽校准必须先于经颅结论。

2. **PlanTUS 式几何规划**
   - 当前 `entry_offset` 和 source safety 还比较工程化。
   - 后续应增加 skin-to-target distance、颅骨厚度、入射角、avoidance proxy。
   - 不默认跑 k-Wave，而是先几何排序，再少量验证。

3. **BabelBrain 式报告和热协议**
   - 保留 explicit pulse、protocol-averaged、constant averaged 的区分。
   - 将热材料参数 profile 化。
   - 报告中清晰写出换能器 profile、声场 preset 和热协议。

### 2.2 中期参考

1. **Kranion / HAS / RapidBeam**
   - 当前 single bowl 先不做复杂相位校正。
   - 但应预留 phase correction profile、array element profile 和 ray/path metrics。

2. **CoperniFUS**
   - 虽偏小动物，但对坐标系统一、脑图谱和实验定位 GUI 有启发。
   - 对人类 CT/k-Wave 主线不是直接求解器参考。

### 2.3 远期参考

1. **TFUScapes / DeepTFUS / tFUSFormer**
   - 可作为 AI surrogate 与数据集组织方向。
   - 需要大量已验证 k-Wave / FDTD 数据作为训练集。
   - 在当前阶段不应用它们替代物理仿真。

## 3. 需要谨慎核实的说法

- DeepTFUS 的年份、数据集规模、误差指标需要查原文；不要直接写成“2023 已发表且误差 5%”。
- tFUSFormer 的指标需要按原文区分：pressure MAE、focal error、SSIM、normalized field 等。
- PRESTUS、TUSX、BabelBrain 的材料映射和热模型应以 README、论文或代码为准，不用二手总结直接定默认值。
- CoperniFUS 偏 stereotaxic FUS experiment planning，不能直接当成人类经颅声场仿真工具。
