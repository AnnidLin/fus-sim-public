# search_results — 检索原始数据

> **作用**：保存文献检索的**原始 CSV 数据**（第二批搜索，见 `00_README.md` 与 `16_20250628_学术搜索补充批次`）。

| 文件 | 主题 | 主要引用笔记 |

| `ct_acoustic_mapping.csv` | CT 声学映射检索数据 | [[07_tFUS文献与公开代码参数对照]] 等 |
| `freefield_calibration.csv` | 自由场校准数据 | [[08_参数对齐报告]] 等 |
| `parameter_effect.csv` | 参数-效应检索数据 | [[MOC_参数与指标]] 等 |
| `safety_reporting.csv` | 安全性报告检索数据 | [[MOC_安全性与临床神经调控]] 等 |
| `skull_validation.csv` | 颅骨验证检索数据 | [[MOC_影像预处理与颅骨建模]] 等 |
