# Current Public-Case Contract

- Current schema: `bbb_public_case_input_v1_2.schema.json`
- Current example: `examples/nlm_public_postmortem_proxy_input_v1_2.json`
- Validator: `bbb_public_case_input_contract.py --verify-files`

Version 1.2 supersedes the NLM v1.1 example after the entry-plan standoff changed
and an independent 15 mm source-material dry-run established that the source is
mixed-medium rather than background-only. Version 1.1 is retained as historical
provenance and must not be used as the current executable contract.

The v1.2 contract does not authorize a new pressure run. It describes a public
postmortem, image-derived proxy input and preserves all hardware, anatomical,
paper-grade, dose, and clinical blockers.
