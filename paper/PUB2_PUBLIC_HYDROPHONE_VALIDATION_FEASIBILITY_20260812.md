# 公开 270 kHz 颅骨水听器数据验证可行性

## 决策

**值得做，且与本项目 250 kHz 最接近；但应作为独立方法验证分支，不能把它说成 Case079 的直接实验验证。**

## 2026-08-12 已完成进展

- 自由场文件 01 已完成许可、MD5/SHA-256、schema 与信号链核验；未下载其余约 2.2 GB 颅骨/CT 子集。
- DRUM 规范确认水听器频响五行依次为频率、V/Pa 灵敏度、幅值不确定度、相位和相位不确定度。原论文确认以随频率变化的水听器灵敏度将示波器电压换算为压力。
- qCW 数据采用中心整数周期、270 kHz 正弦/余弦/DC 最小二乘拟合；270 kHz 插值灵敏度为 `2.3400e-8 V/Pa`，标称幅值不确定度 9%。
- 实测轴向峰值为 **0.4236 MPa**，细化峰位距换能器面 **49.006 mm**。39.998 mm 横向平面峰值为 **0.3306 MPa**，中心偏移小于 0.03 mm；它与隔日轴向扫描在同一 z 的插值只差 **+0.0209%**。
- 横向平面 -6 dB 宽为 8.233 x 8.014 mm，但该平面位于焦前，不能称为焦宽。轴向 -6 dB 区域超出 90 mm 扫描远端，只能报告 **>54.707 mm** 的删失下界。
- H115 等效碗水域模型已通过 standard 和 paper-grade dry-run：dx0.50 mm、10.98 PPW、PML16、CFL0.10、5,337 步；没有启动传播。paper-grade 状态仍明确缺少网格收敛、PML review 与环境记录集成。

当前结论是：**公开测量已经从“可用数据源”推进为可审计的自由场验证合同，但还没有形成测量–仿真吻合结果。**

## 2026-08-18 受控自由场比较结果

已执行一次且仅一次 H115 均匀水域传播（dx 0.50 mm、10.98 PPW、PML16、CFL0.10）；输出、设备记录和独立包校验均通过，运行时没有触发 CPU、内存或空闲内存门限。轴向峰值仅用于一个数值幅值比例因子，其他端点保持留出。

该比较**没有通过**冻结验收合同：轴向峰位差 1.856 mm（门限 <=1.0 mm）、横向归一化 L2 为 15.004%（<=10%）。2026-08-25 的回归审计发现旧线宽提取把微米级坐标抖动误作网格步长；修正后 y 向 -6 dB 宽度误差为 +5.989%，通过冻结 ±10% 门槛。虽然其余端点也通过，但不能选择性报告。因此它仍是非通过的工程观察，不是 Case079、颅骨、热学、安全性或临床验证。

## 2026-08-23 网格敏感性结论

新增一次 dx0.30 mm（18.30 PPW）完整物理域计算，用于判断前述失配是否主要来自 dx0.50 mm 网格。该运行耗时 6.41 h，设备与产物独立校验全部通过。与 dx0.50 mm 场按源中心物理坐标对齐后，相关性为 0.999881、幅值拟合后 L2 为 1.310%、峰值变化 +0.0307%、离散轴向峰位变化 0 mm，说明模拟场对网格细化较稳定。

但两个真实失败端点没有改善：轴向峰位误差增至 2.177 mm，横向 L2 增至 15.469%；修正后的 y 向宽度误差为 +7.160%并通过。继续单纯细化网格不太可能解决当前验证失败，两级网格仍不足以声明正式收敛。

## 2026-08-25 源模型与配准修订

依据公开 HDF5 独立记录的 64 mm 曲率半径、64 mm 外径、45.47 mm 环分界及两通道等功率零相位，建立了新 Evidence Brief，并仅运行一个名义几何候选。该候选显著恶化：轴向峰位误差 10.028 mm、轴向 L2 31.030%、横向 L2 118.286%。因此保留论文拟合的 61.39/50.40 mm 等效碗，而不能把名义外形视为更忠实且更准确的替代。

描述性配准扫描显示 +1.0 mm 是令等效碗轴向峰位通过的最小冻结偏移，但没有独立自由场原点不确定度支持实际应用该修正。0.2 mm 水听器孔径的幅值域近似平均只将横向 L2 从 15.004% 改为 15.039%，不具解释力。下一步若继续传播，必须先取得逐环声学幅相标定或冻结测量复全息源合同；本轮不再授权求解器。

公开数据集为 Krokhmal 等的 *A Comparative Study of Experimental and Simulated Ultrasound Beam Propagation Through Cranial Bones*，UCL Research Data Repository DOI `10.5522/04/28025240.v2`，CC BY 4.0。公开 API 显示 v2 共 22 个文件、约 8.14 GB，其中 18 个 HDF5 测量文件和 4 个配准后的 0.35 mm 等体素 CT NIfTI。

## 数据能验证什么

- 自由场源模型能否重现 H115-2AA 的平面和轴向场；
- CT→密度/声速/衰减映射和传播流程能否重现四个离体颅骨后的 270 kHz 场；
- 峰值压力误差、焦点位置、−6 dB 焦区尺寸/体积和完整平面场差异；
- bowl source 与测量源表征之间的误差边界。

不能验证：

- Case079 个体的真实颅内压力；
- 本项目 250 kHz 两周期激励的完全频率/波形等价性；
- 活体组织、灌注、热效应、神经调控效果或安全性。

## 推荐执行顺序

1. ~~只下载自由场文件 01，先解析 HDF5 schema、坐标、单位、PW/qCW 波形和校准信息；~~ 已完成 qCW 路径；PW 宽带路径仍待滤波/Tukey敏感性合同。
2. 用已冻结的 H115 等效碗水域模型做一次受控验证：轴向峰值只用于拟合一个线性幅值标量，轴向形状/峰位及独立横向平面作为留出端点；
3. 选择 Skull A 或 D 做一个 270 kHz pilot，依据公开 CT 仿真并与平面/轴向水听器场对齐；
4. 在看其他颅骨结果前冻结误差指标和合同；
5. 再扩展至 B/C/D，报告中位数、范围和最差个例，不只报告平均值；
6. 最后评估 270→250 kHz 的频率差能否通过额外敏感性分析支持，而不是直接等同。

## 预注册指标

- 空间峰值压力相对误差；
- 三维或可用维度的峰值位置差；
- −6 dB 长、宽和体积误差；
- common-grid 的归一化 L2/L∞ 和相关系数；
- 自由场与经颅结果分别报告；
- source scaling、hydrophone spatial averaging、配准误差和 CT 映射不确定性单列。

## 风险与控制

- 数据频率是 270 kHz 而项目是 250 kHz：只称“邻近频率方法验证”；
- H115-2AA 为两阵元环形阵列，和当前 bowl 并不相同：必须先做源表征，不能直接套用几何参数；
- 水听器存在空间平均和校准不确定度：保留原始测量分辨率与探头尺寸，并在误差预算中体现；
- 论文研究显示衰减映射会显著影响压力而对场形影响相对较弱：压力和定位/形状必须分开判断；
- Skull B 在 270 kHz 是明显异常/强畸变场景：不能删除，应作为压力测试个例。
- qCW HDF5 实际记录为 50 MHz、约5个稳定周期，和论文所述125 MHz、10--20周期不完全一致：处理必须以文件元数据为准并保留该偏差。
- PW 处理虽有论文框架（0.1--3 MHz、Tukey、频域复灵敏度），但滤波器与Tukey参数未公开：在敏感性分析前不报告PW绝对压力。
- 轴向扫描未覆盖完整 -6 dB 区域：不能用当前文件给出完整轴向焦深。
